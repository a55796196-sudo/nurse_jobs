본문 미리보기 (접기)

 

회의록은 대화를 받아 적는 것이 아니라
결정 사항, 할 일, 담당자, 기한을 남기는 문서입니다.
업무 메일도 제목만 보고 무슨 일인지 알 수 있게 쓰는 것이 핵심입니다.

연구 회의, 사업 회의, 협력 기관 메일 같은 장면에서
바로 쓸 수 있는 틀을 정리해 보겠습니다.

 

회의록·메일 기본, 한눈에 보기

핵심만 정리하면 이렇습니다.

 

✔️ 회의록 : 일시·참석자, 안건, 결정 사항, 할 일(담당자·기한)
✔️ 메일 제목 : [요청], [안내], [회신]처럼 목적을 앞에
✔️ 메일 본문 : 결론(요청) → 배경 → 세부 내용 → 회신 기한
✔️ 공통 : 짧은 문장, 번호 목록

 

회의록은 어떤 틀로 쓸까?

회의록은 일시·장소·참석자를 적고,
안건별로 논의 요약과 결정 사항을 나눠 씁니다.

마지막에 할 일을 내용·담당자·기한으로 표로 정리하면
회의가 끝난 뒤 누가 무엇을 해야 하는지 분명해집니다.
연구 회의나 사업 회의에서 특히 쓸모가 큽니다.

 

(💡 회의 중에는 키워드만 적고, 끝나고 30분 안에 정리해서 공유하면 기억이 정확할 때 마무리할 수 있습니다)

 

업무 메일 제목은 어떻게 쓸까?

제목만 보고 무엇을 해야 하는지 알 수 있게 씁니다.
'[목적] 내용 요약 (기한)' 형태가 무난합니다.

예를 들어 '[요청] 3월 교육 참석자 명단 회신 (3/5까지)'처럼 쓰면
받는 사람이 메일을 열기 전부터 할 일을 알 수 있습니다.

 

업무 메일 본문은 어떻게 쓸까?

인사 뒤 첫 문단에 결론이나 요청을 씁니다.
배경과 세부 내용은 번호 목록으로 나누고,
회신이 필요하면 기한을 분명히 적습니다.

마지막에 문의할 연락처를 남기면 주고받는 메일 횟수가 줄어듭니다.

 

회의록·메일에서 주의할 점은?

✔️ 개인정보 : 대상자 정보는 본문에 쓰지 말고 기관 규정에 맞는 방식으로 전달
✔️ 수신 범위 : 받는 사람·참조·전체 회신 범위 확인
✔️ 첨부 : 파일을 빠뜨리거나 다른 파일을 붙이지 않았는지 확인
✔️ AI 활용 : 문장 다듬기는 AI에 맡겨도 되지만 개인정보는 넣지 않기

 

회의록과 메일은 매일 쓰는 만큼
