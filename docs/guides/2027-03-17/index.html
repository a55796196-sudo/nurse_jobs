본문 미리보기 (접기)

 

사회복지사 2급은 시험 없이 사회복지 교과목 이수와 현장실습으로 취득하는 국가자격입니다.
정신건강, 자살예방, 재난심리처럼
간호사와 사회복지사를 함께 자격 요건으로 두는 지역사회 사업 공고가 있어
이 분야를 노리는 간호사에게 선택지를 넓혀 줍니다.

취득 방법과 활용처를 정리해 보겠습니다.

 

사회복지사 2급 한눈에 보기

먼저 핵심만 정리하면 이렇습니다.

 

✔️ 취득 방식 : 시험 없이 사회복지 교과목 이수 + 현장실습
✔️ 교과목 : 전문대졸 이상은 17과목(필수 10, 선택 7) 이수
✔️ 현장실습 : 160시간 이상 (온라인 대체 불가)
✔️ 기간 : 학점 상한 때문에 최소 3학기 정도 소요

 

사회복지사 2급은 어디에 쓰일까?

최근 수집한 공고에서도 간호사와 사회복지사를 함께 자격으로 둔 경우가 있었습니다.

 

✔️ 홍성군보건소 자살예방사업 : 간호사, 임상심리사, 사회복지사 등 자격 소지자
✔️ 대한적십자사 재난심리 : 간호사 면허 또는 사회복지사 2급 이상 등 중 1개 이상
✔️ 단, 의료사회사업처럼 사회복지사 1급을 요구하는 자리도 있음

 

(💡 이런 공고는 간호사 면허만으로도 지원할 수 있어, 사회복지사 2급은 같은 분야에서 업무 폭을 넓히고 싶을 때 의미가 있습니다)

 

사회복지사 2급은 어떻게 취득할까?

전문대졸 이상이라면 학점은행제 등으로 사회복지 17과목을 이수하면 됩니다.
이론 과목은 온라인 수강이 가능하지만
현장실습 160시간은 실제 기관에서 해야 하고,
실습세미나도 일부는 대면으로 진행됩니다.

한 학기 이수 학점에 상한이 있어
대졸자도 최소 3학기 정도 걸립니다.

 

간호사가 따면 무엇이 달라질까?

정신건강복지센터, 치매안심센터, 방문건강관리처럼
보건과 복지가 함께 움직이는 사업에서는
두 분야를 모두 이해하는 사람이 강점을 가집니다.

다만 이런 사업 대부분은 간호사 면허만으로도 지원할 수 있으니
시간과 비용을 들일 만큼 이 분야에 오래 있을 계획인지 먼저 생각해 보는 것이 좋습니다.

 

간호사에게 필요한 경우, 아닌 경우

✔️ 있으면 좋은 경우 : 정신건강·자살예방·지역사회 복지 연계 사업에서 오래 일할 계획일 때
✔️ 급하지 않은 경우 : 간호사 면허만으로 지원 가능한 자리에 먼저 들어가 경력을 쌓을 때
✔️ 우선순위가 낮은 경우 : 보건관리자, CRC, RA처럼 기업·연구 직무가 목표일 때

 

 

사회복지사 2급은 지역사회와 정신건강 분야에서
간호사의 업무 폭을 넓혀 주는 자격입니다.

다만 시간과 실습이 필요한 만큼
목표 분야가 분명할 때 시작하는 것을 추천합니다.
