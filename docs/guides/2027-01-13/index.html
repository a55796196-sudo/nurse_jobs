엑셀 피벗테이블로 월별 통계 내기: 보고서용 집계 따라 하기 (보건사업·검진 실적)
본문 미리보기 (접기)

 

피벗테이블은 많은 행의 데이터를 월별·항목별로
클릭 몇 번 만에 집계해 주는 엑셀 기능입니다.
보건사업 실적, 상담 건수, 검진 사후관리 현황처럼
매달 보고서에 들어가는 숫자를 만들 때 특히 유용합니다.

예시 데이터로 월별 통계를 내 보겠습니다.

 

피벗테이블, 한눈에 보기

순서만 정리하면 이렇습니다.

 

✔️ 원본 정리 : 한 건을 한 행으로, 맨 위에 머리글
✔️ 만들기 : [삽입] → [피벗 테이블]
✔️ 배치 : 행·열·값 영역에 필드를 끌어다 놓기
✔️ 갱신 : 원본이 바뀌면 [새로 고침]

 

피벗테이블을 쓰려면 원본을 어떻게 정리할까?

피벗테이블은 원본이 깔끔해야 제대로 동작합니다.
한 건(상담 1건, 방문 1건)을 한 행으로 두고,
맨 위에 머리글(날짜, 사업명, 구분 등)을 둡니다.

중간의 빈 행과 병합된 셀은 없애고
날짜는 날짜 형식으로 입력해야 월별로 묶을 수 있습니다.

 

월별 통계는 어떻게 낼까?

날짜 필드를 행 영역에 놓고
날짜를 월 단위로 그룹화합니다.
(버전에 따라 자동으로 월·분기로 묶이기도 합니다.)

사업명이나 구분을 열 영역에 두고,
건수를 셀 필드를 값 영역에 놓은 뒤 '개수'로 바꾸면
월별·사업별 실적표가 완성됩니다.

 

(💡 값이 '합계'로 나오면 값 필드 설정에서 '개수'로 바꿔야 건수가 나옵니다)

 

보고서에 넣을 때는 어떻게 할까?

보고서 필터 영역에 부서나 사업을 넣으면
원하는 범위만 골라 볼 수 있습니다.

보고서 양식에 옮길 때는 피벗 결과를 복사해
값만 붙여넣기 하면 서식이 깨지지 않습니다.
원본이 바뀌었다면 [새로 고침]을 꼭 누르세요.

 

피벗테이블 쓸 때 주의할 점은?

✔️ 범위 : 원본에 행을 추가했는데 범위에 안 들어가는 실수가 잦음
✔️ 표 기능 : 원본을 표(Ctrl+T)로 만들어 두면 범위가 자동으로 늘어남
✔️ 공유 : 피벗 결과에 개인 식별 정보가 보이지 않는지 확인 후 공유

 

 

피벗테이블은 한 번 익히면
매달 반복되는 집계 업무를 몇 분으로 줄여 줍니다.

다음 실무 스킬에서는
공문·보고서의 기본 형식을 다룹니다.
