💡 2027-03-03 탈임상 가이드

블로그 글카테고리: 탈임상 가이드 > 병원 밖 업무 스킬
컴퓨터활용능력, 탈임상 간호사에게 필요할까? 공공기관·보건소 공고에서 쓰이는 곳과 준비법
본문 미리보기 (접기)

 

컴퓨터활용능력은 대한상공회의소가 시행하는 국가기술자격으로,
엑셀 등 사무 프로그램 활용 능력을 평가합니다.
탈임상 직무는 문서와 데이터 업무가 많아
공공기관·보건소 공고에서 우대나 서류 평가 항목으로 등장합니다.

쓰이는 곳과 준비 방법을 정리해 보겠습니다.

 

컴퓨터활용능력 한눈에 보기

먼저 핵심만 정리하면 이렇습니다.

 

✔️ 종류 : 국가기술자격 (대한상공회의소 시행)
✔️ 등급 : 1급, 2급 (필기와 실기)
✔️ 평가 내용 : 스프레드시트(엑셀)·데이터베이스 등 사무 프로그램 활용
✔️ 쓰이는 곳 : 공공기관·보건소·병원 행정성 직무 공고의 우대·가점

 

컴활은 어떤 공고에서 쓰일까?

최근 수집한 공고에서도 이렇게 등장했습니다.

 

✔️ 국민건강보험공단 일산병원 간호사 공고 : 컴퓨터활용능력 1·2급, 워드프로세서 등을 자격 항목으로 제시
✔️ 원주시보건소 방문건강관리 간호사 : 엑셀·워드 등 컴퓨터 관련 자격을 서류전형에서 확인

 

(💡 같은 컴퓨터 자격이라도 기관마다 인정 종목과 가점이 달라 목표 기관 공고의 자격 목록을 먼저 확인하세요)

 

탈임상 직무에서 엑셀이 왜 중요할까?

보건소 사업 대상자 명단, 보건관리자의 검진 결과 관리,
CRC의 연구 자료 정리처럼
탈임상 직무는 엑셀을 쓰는 일이 많습니다.

자격증은 그 능력을 서류에서 보여주는 수단이고,
실제 업무에서는 활용 능력이 더 중요합니다.

 

컴활은 어떻게 준비할까?

✔️ 등급 : 처음이라면 2급부터 시작하는 경우가 많음
✔️ 필기 : 기출 문제 위주로 유형 익히기
✔️ 실기 : 함수·기능을 직접 반복 연습
✔️ 일정 : 상시 시험 일정과 응시료는 대한상공회의소 자격평가사업단에서 확인

 

간호사에게 필요한 경우, 아닌 경우

✔️ 있으면 좋은 경우 : 공공기관·보건소 등 컴퓨터 자격을 우대하는 곳이 목표일 때, 엑셀 기본기를 체계적으로 익히고 싶을 때
✔️ 급하지 않은 경우 : 목표 직무 공고에 컴퓨터 자격 언급이 거의 없을 때

 

컴활은 서류의 한 줄이기도 하지만
탈임상 업무의 기본기이기도 합니다.

엑셀 실무 활용법은
수요일 실무 스킬 글에서 따라 하기 형식으로 다룹니다.
