엑셀 그래프로 한 장짜리 보고서 만들기: 어떤 그래프를 고를까, 보기 좋게 다듬는 법
본문 미리보기 (접기)

 

한 장짜리 보고서는 핵심 숫자 몇 개와
그 흐름을 보여주는 그래프 한두 개로 만드는 것이 효과적입니다.
엑셀에서는 비교는 막대, 추이는 꺾은선을 기본으로 고르면 대부분 해결됩니다.

그래프 고르는 법과 보기 좋게 다듬는 법을 정리해 보겠습니다.

 

엑셀 그래프 보고서, 한눈에 보기

기본만 정리하면 이렇습니다.

 

✔️ 비교(사업별·부서별) : 막대 그래프
✔️ 추이(월별 변화) : 꺾은선 그래프
✔️ 구성비 : 항목이 적을 때만 원형 그래프
✔️ 제목 : '월별 상담 건수'보다 '상담 건수 3개월 연속 증가'처럼 결론을

 

어떤 그래프를 골라야 할까?

항목끼리 크기를 비교할 때는 막대 그래프,
월별처럼 시간에 따른 변화를 보여줄 때는 꺾은선 그래프가 기본입니다.

원형 그래프는 항목이 많아지면 비교가 어려워
항목이 적을 때만 쓰는 것이 좋습니다.

 

그래프는 어떻게 만들까?

그래프로 만들 표 범위를 선택하고
[삽입] 탭에서 원하는 차트를 고릅니다.
[추천 차트]로 시작해도 충분합니다.

지난 실무 스킬에서 만든 피벗테이블 결과로
피벗 차트를 바로 만들 수도 있습니다.

 

그래프를 보기 좋게 다듬으려면?

✔️ 줄이기 : 불필요한 눈금선, 3D 효과, 과한 색 없애기
✔️ 강조 : 말하고 싶은 항목 하나만 진한 색, 나머지는 회색
✔️ 숫자 : 데이터 레이블로 막대·점 위에 값 표시
✔️ 축 : 세로축 시작값이 0이 아니면 차이가 과장되어 보일 수 있어 주의

 

(💡 그래프 제목에 결론을 쓰면 읽는 사람이 그래프에서 무엇을 봐야 하는지 바로 알 수 있습니다)

 

한 장 보고서는 어떻게 구성할까?

맨 위에 핵심 결론 2~3줄,
가운데에 그래프 1~2개,
아래에 다음 계획이나 요청 사항을 두면
한 장 안에 이야기가 완성됩니다.

개인 식별 정보가 보이는 표나 그래프는 넣지 않습니다.

 

 

좋은 그래프는 화려한 그래프가 아니라
한눈에 결론이 보이는 그래프입니다.

지금까지의 실무 스킬 글(명단 관리, 관리표, 피벗테이블, 문서 형식)을 함께 활용하면
탈임상 문서 업무의 기본기는 갖춘 셈입니다.
