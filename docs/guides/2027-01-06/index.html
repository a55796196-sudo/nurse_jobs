보건교육사, 간호사에게 필요할까? 국가자격 등급·응시자격·보건소·공공기관에서 쓰이는 곳
본문 미리보기 (접기)

 

보건교육사는 국민건강증진법에 근거한 국가자격으로,
1·2·3급으로 나뉘고 한국보건의료인국가시험원이 시험을 시행합니다.
보건소 건강증진 사업이나 공공기관 채용에서
자격 요건 또는 우대 조건으로 등장합니다.

어떤 자격인지와 간호사에게 필요한 경우를 정리해 보겠습니다.

 

보건교육사 한눈에 보기

먼저 핵심만 정리하면 이렇습니다.

 

✔️ 종류 : 국민건강증진법에 근거한 국가자격
✔️ 등급 : 1급, 2급, 3급
✔️ 시험 : 한국보건의료인국가시험원(국시원) 시행
✔️ 쓰이는 곳 : 보건소 건강증진 사업, 금연·건강교육, 공공기관 채용

 

보건교육사는 어디에 쓰일까?

최근 홍성군보건소 금연상담사 공고는
간호학 등 보건의료 관련 전공자 또는 보건교육사를 자격 요건으로 적었습니다.

국민건강보험공단 건강직 채용 공고에도
간호사 등과 함께 보건교육사(2급 이상)가 자격 목록에 포함된 적이 있습니다.

 

(💡 간호사 면허로 이미 지원 가능한 공고가 많아, 보건교육사는 건강증진·교육 사업에 특화하고 싶을 때 더 의미가 있습니다)

 

보건교육사 응시자격은?

등급별 응시자격은 국민건강증진법 시행령에 정해져 있고,
보건교육 관련 과목 이수나 경력 등의 요건이 있습니다.

간호학 전공 과정에서 이수한 과목이 인정되는지는 개인마다 다를 수 있으니
국시원의 해당 연도 시행계획 공고와 응시자격 안내로 확인하는 것이 정확합니다.

 

보건교육사 시험은 어떻게 준비할까?

시험 과목과 일정은 국시원 공고에서 확인합니다.
보건교육과 건강증진 이론이 중심이라
간호학에서 배운 지역사회간호와 겹치는 부분이 있어
간호사에게 낯설지 않은 편입니다.

 

간호사에게 필요한 경우, 아닌 경우

✔️ 있으면 좋은 경우 : 보건소 건강증진·금연·교육 사업, 공공기관 보건 관련 직렬이 목표일 때
✔️ 급하지 않은 경우 : 보건관리자, CRC, 보험심사처럼 다른 자격·경력이 더 중요한 직무가 목표일 때

 

 

보건교육사는 간호사 면허와 함께 있으면
건강증진·교육 분야에서 강점이 되는 국가자격입니다.

보건소 사업을 목표로 한다면 고려해 볼 만합니다.
