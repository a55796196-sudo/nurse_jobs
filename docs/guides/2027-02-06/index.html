QI(의료질관리) 간호사는 어떤 일을 할까? 인증평가·적정성평가·환자안전 업무 정리
본문 미리보기 (접기)

 

QI 간호사는 병원의 의료 질 향상과 환자안전을 담당하며
의료기관 인증평가, 적정성평가 같은 외부 평가를 준비하는 직무입니다.
병원 소속이지만 환자를 직접 간호하지 않는 대표적인 비임상 자리입니다.

하는 일과 필요한 역량을 정리해 보겠습니다.

 

QI 간호사 한눈에 보기

먼저 핵심만 정리하면 이렇습니다.

 

✔️ 주요 업무 : 의료 질 지표 관리, 질 향상 활동, 외부 평가 준비
✔️ 외부 평가 : 의료기관 인증평가, 건강보험심사평가원 적정성평가 등
✔️ 환자안전 : 환자안전사건 보고·분석·개선 활동 (병원마다 별도 팀인 경우도)
✔️ 근무처 : 병원 QI팀(부서 이름은 병원마다 다름), 주간 근무

 

QI 간호사는 어떤 일을 할까?

✔️ 질 지표 관리 : 진료 과정·결과 지표 자료 수집과 분석
✔️ 외부 평가 준비 : 의료기관 인증평가 기준 점검, 적정성평가 자료 관리
✔️ 개선 활동 : 문제 지표에 대한 개선 활동 기획, 부서 협업
✔️ 교육·보고 : 직원 교육, 결과 보고서 작성

 

인증평가와 적정성평가는 무엇일까?

의료기관 인증평가는 병원의 의료 질과 환자안전 수준을 평가하는 제도이고,
적정성평가는 건강보험심사평가원이 질병별 진료 과정과 결과를 지표로 평가하는 제도입니다.

QI 간호사는 병원 안에서 이 평가들을 준비하고
결과를 바탕으로 개선 활동을 이끄는 역할을 합니다.
그래서 보험심사 부서와 업무가 겹치기도 합니다.

 

QI 간호사에게 필요한 역량은?

✔️ 임상 경력 : 진료 과정과 현장 상황을 알아야 지표와 개선안이 현실적
✔️ 데이터 : 엑셀로 자료를 정리·분석하는 능력
✔️ 의사소통 : 여러 부서와 협업하고 설득하는 능력
✔️ 문서 : 보고서와 교육 자료 작성

 

(💡 QI 관련 교육은 한국의료질향상학회, 한국QI간호사회 같은 학회의 연수 과정으로 운영되며, 국가 자격 제도는 따로 없습니다)

 

QI 간호사, 이런 분께 잘 맞습니다

✔️ 병원을 떠나지 않고 비임상 업무를 하고 싶은 분
✔️ 숫자와 지표로 문제를 찾고 개선하는 일에 흥미가 있는 분
✔️ 여러 부서를 조율하는 역할이 편한 분

 

QI 간호사는 병원 안에 있으면서도
환자 대신 병원 전체의 질을 돌보는 직무입니다.

업무가 일부 겹치는 보험심사 간호사는
'보험심사 간호사는 어떤 일을 할까?' 글에서 정리했습니다.
