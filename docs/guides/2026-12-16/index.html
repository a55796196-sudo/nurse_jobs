엑셀 기본기: 대상자 명단 관리하는 법 (필터·정렬·중복 제거·VLOOKUP/XLOOKUP 따라 하기)
본문 미리보기 (접기)

 

대상자 명단 관리는 보건소 사업, 보건관리자 업무, 연구 대상자 관리 등
탈임상 직무에서 가장 자주 하는 엑셀 작업입니다.
필터, 정렬, 중복 제거, 찾기 함수(VLOOKUP·XLOOKUP) 네 가지만 익혀도
대부분의 명단 작업을 처리할 수 있습니다.

예시 명단으로 하나씩 따라 해 보겠습니다.

 

엑셀 명단 관리, 한눈에 보기

명단 관리에 꼭 필요한 기능은 네 가지입니다.

 

✔️ 필터 : 지역·대상 구분 등 원하는 조건의 사람만 보기
✔️ 정렬 : 방문일·이름·번호 순으로 정리
✔️ 중복 제거 : 같은 사람이 두 번 들어간 행 없애기
✔️ VLOOKUP·XLOOKUP : 다른 표에서 연락처·결과 등 정보 가져오기

 

(💡 연습할 때는 실제 대상자 정보 대신 '대상자1, 대상자2'처럼 가상의 예시 명단을 만들어 쓰세요)

 

필터와 정렬은 어떻게 쓸까?

명단 맨 위 머리글 행을 선택하고
[데이터] 탭에서 [필터]를 누르면 각 열에 화살표가 생깁니다.
화살표를 눌러 원하는 값만 체크하면 그 조건의 사람만 보입니다.

정렬은 같은 화살표나 [데이터] 탭의 [정렬]에서
기준 열을 정하고 오름차순·내림차순을 고르면 됩니다.

 

중복된 사람은 어떻게 없앨까?

명단 범위를 선택하고
[데이터] 탭에서 [중복된 항목 제거]를 누릅니다.
이때 어떤 열이 같으면 같은 사람으로 볼지 기준 열을 정합니다.

이름만 기준으로 하면 동명이인이 지워질 수 있어
이름과 생년월일처럼 두 개 이상을 함께 고르는 것이 안전합니다.
지우기 전에는 원본 시트를 복사해 두세요.

 

다른 표에서 정보를 가져오려면? (VLOOKUP·XLOOKUP)

명단에 있는 번호로 다른 표의 연락처나 결과를 가져올 때 씁니다.

VLOOKUP은 =VLOOKUP(찾을 값, 표 범위, 가져올 열 번호, FALSE) 형태로,
찾을 값이 표 범위의 맨 왼쪽 열에 있어야 합니다.

XLOOKUP은 =XLOOKUP(찾을 값, 찾을 범위, 가져올 범위) 형태로
열 위치와 상관없이 쓸 수 있어 더 편합니다.
다만 최신 버전의 엑셀에서만 사용할 수 있습니다.

 

(💡 결과가 #N/A로 나오면 찾을 값에 띄어쓰기나 형식(숫자·텍스트) 차이가 없는지 먼저 확인하세요)

 

명단 관리할 때 지킬 것은?

✔️ 보안 : 개인정보가 담긴 파일은 기관 규정에 따라 보관·전송 (개인 메일·메신저 전송 주의)
✔️ 원본 보관 : 원본 시트와 작업 시트를 분리
✔️ 형식 통일 : 날짜·전화번호 형식을 처음부터 통일하면 함수 오류가 줄어듦

 

 

필터, 정렬, 중복 제거, 찾기 함수만 손에 익혀도
명단 업무 시간이 크게 줄어듭니다.
