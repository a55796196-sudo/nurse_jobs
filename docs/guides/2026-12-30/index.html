엑셀로 건강검진·유소견자 관리표 만들기 (보건관리자 업무 예시, COUNTIF·조건부 서식)
본문 미리보기 (접기)

 

보건관리자 업무에서는 건강검진 결과를 정리하고
유소견자의 상담·재검 여부를 꾸준히 관리해야 합니다.
엑셀로 관리표를 만들어 두고 조건부 서식과 COUNTIF를 쓰면
누가 아직 관리가 필요한지 한눈에 볼 수 있습니다.

가상의 예시로 관리표를 만들어 보겠습니다.

 

유소견자 관리표, 한눈에 보기

관리표는 이렇게 구성합니다.

 

✔️ 열 구성 : 관리번호, 부서, 검진 판정, 관리 항목, 상담일, 재검 여부, 비고
✔️ 조건부 서식 : 상담·재검이 끝나지 않은 행을 색으로 표시
✔️ COUNTIF : 판정별 인원, 상담 완료 인원 세기
✔️ 필터 : 부서별·판정별로 골라 보기

 

(💡 이름 대신 관리번호를 쓰고, 실제 검진 결과 파일은 기관 규정에 맞게 보관하세요. 연습은 가상의 예시 데이터로 합니다)

 

관리표 열은 어떻게 구성할까?

한 사람을 한 행으로 두고,
판정(예: 정상, 주의, 관리 필요)과 여부(예: 완료, 미완료)는
정해진 값으로만 입력하도록 통일합니다.

값이 제각각이면 집계와 필터가 틀어지기 때문입니다.
[데이터 유효성 검사]로 목록을 만들어 두면 선택만 하면 돼서 편합니다.

 

관리가 필요한 사람을 색으로 표시하려면?

재검 여부 열을 선택하고
[홈] 탭의 [조건부 서식] → [셀 강조 규칙] → [같음]에서
'미완료'에 색을 지정하면 아직 관리가 필요한 사람이 바로 보입니다.

행 전체에 색을 칠하고 싶다면
[새 규칙]에서 수식을 사용해 규칙을 만들 수 있습니다.

 

판정별 인원은 어떻게 셀까? (COUNTIF)

COUNTIF는 조건에 맞는 칸의 개수를 셉니다.
=COUNTIF(판정 열 범위, "관리 필요")처럼 쓰면 관리 필요 인원이 나옵니다.

조건이 두 개라면 COUNTIFS를 씁니다.
예를 들어 '관리 필요'이면서 '미완료'인 인원을 셀 수 있어
월별 보고서에 바로 쓸 수 있습니다.

 

관리표를 업무에 쓸 때 주의할 점은?

✔️ 민감정보 : 건강검진 결과는 민감한 개인정보라 보관·공유를 기관 규정대로
✔️ 권한 : 파일 열람 권한은 필요한 사람만
✔️ 기록 : 상담일·조치 내용을 날짜와 함께 남겨 두기
✔️ AI 사용 : 검진 결과 파일을 AI에 올리지 않기

 

관리표는 한 번 잘 만들어 두면
매달 사후관리와 보고가 훨씬 쉬워집니다.
