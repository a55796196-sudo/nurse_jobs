# 초안: 탈임상 첫 출근, 챙기면 좋은 물품 (병원 밖 출근 생활 1편)

- 상태: 사용자 사진·후기 대기 (다음 주 예정). 날짜 파일로 만들지 말 것 — 자동 작업이 쓰지 않는다.
- 카테고리(네이버): 새로 만들 "병원 밖 출근 생활" (가이드 글과 분리)
- 개인정보: '사무직 n년차'·회사명·사원증·모니터 화면·사내 비품 로고·창밖 풍경이 나오지 않게. 일반 표현 "탈임상 후 첫 사무직 출근".
- 협찬·제휴 링크가 들어가면 글 첫머리에 표시 문구 (쿠팡 파트너스면 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.")

## 글 구성 (안)
1. 도입: 병원 출근과 사무직 출근이 다른 점 (근무복·사물함 대신 내 자리, 하루 대부분 앉아서 모니터)
2. 책상 기본템: 노트북 거치대·모니터 받침, 마우스·키보드, 손목 받침
3. 앉아서 오래 일하는 몸을 위해: 등받이 쿠션·발받침, 블루라이트/눈 피로 관련, 텀블러
4. 정리·업무용: 다이어리·포스트잇(할 일 관리), 서류 파일, 멀티탭·충전기
5. 옷·소지품: 근무복이 없으니 출근복, 카디건(사무실 냉난방), 실내화
6. 마무리: 처음부터 다 살 필요 없다 → 일주일 써 보고 필요한 것부터

## 사용자에게 받을 것
- 실제로 쓰는 물품 3~7개 + 각 물품 사진 1장
- 물품마다 한두 줄 후기 (왜 좋은지, 아쉬운 점)
- 제휴 링크를 쓸지 여부 (쓰면 링크)
