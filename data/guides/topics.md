# 탈임상 가이드 주제 대기열

- 가이드는 주 3편: 수(자격증↔실무 스킬) · 토(직접 던진 주제 → 직무 기본 가이드 → 기본 주제) · 일(자소서·면접). 각 목록 위에서부터 씁니다. 쓰고 나면 `- [x] 주제 (YYYY-MM-DD)` 로 표시돼요.
- 쓰고 싶은 주제가 생기면 맨 위 "직접 던진 주제"에 `- [ ] 주제` 한 줄만 추가하세요. (GitHub 앱에서 바로 편집하거나, Claude에게 말해도 됩니다)
- 카테고리: 자소서/면접 · 병원 밖 업무 스킬
- 직무 시리즈는 **직무 소개 → 취준 → 입사 후 → 이직** 순서로 쓴다.
- 경험·견해 메모는 `notes/` 폴더에. 메모가 있는 주제를 우선 쓴다. 메모가 없어도 리서치로 쓸 수 있다.
